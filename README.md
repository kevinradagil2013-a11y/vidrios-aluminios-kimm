# Vidrios y Aluminios Kimm

Sitio web corporativo y portafolio visual de Vidrios y Aluminios Kimm.

## Arquitectura

- Frontend: React + Vite + TypeScript
- Catalog Service: Node.js + TypeScript
- Contact Service: Node.js + TypeScript
- Base de datos: PostgreSQL
- Deployment: Render

## Concepto

Kimm no será una tienda online.

Será una experiencia visual para:

- mostrar referencias;
- mostrar proyectos;
- mostrar procesos;
- presentar videos;
- inspirar al cliente;
- generar solicitudes de cotización.
